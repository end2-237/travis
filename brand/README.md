# Source de l'identité

`travis-logo-source.jpg` est le fichier d'origine fourni par la marque —
1408 × 768, fond blanc.

Les déclinaisons de `public/brand/` en sont extraites : détourage du blanc,
recadrage au contenu, séparation de la marque et du nom, variante blanche
pour les fonds sombres. Le script de génération vit dans l'historique de la
session ; il suffit de refaire l'opération depuis ce fichier si l'artwork
change.

Rien n'est redessiné : une reconstitution approchée d'un logo est un autre
logo.

| Fichier | Usage |
| --- | --- |
| `public/brand/travis-logo.png` | bloc complet, fonds clairs |
| `public/brand/travis-logo-blanc.png` | bloc complet, fonds sombres |
| `public/brand/travis-marque.png` | marque seule, carrée |
| `public/brand/travis-marque-blanc.png` | marque seule, fonds sombres |
| `public/brand/icone-512.png` | source du favicon et de l'icône PDF |
| `src/app/icon.png` · `src/app/apple-icon.png` | favicons, générés par Next |
